# BVS Business Center website handoff

## Preview

https://bvs-homepage-concepts.workspace-384730.chatgpt.site

## Project structure

- `app/page.tsx` — homepage content, navigation, FAQ and enquiry-form design
- `app/globals.css` — the complete Quiet Prestige visual system and responsive layout
- `app/layout.tsx` — page title, description and social-sharing metadata
- `public/` — authentic BVS Business Center photographs and social-preview artwork

## Local setup

1. Install Node.js 22.13 or newer.
2. Run `npm install`.
3. Run `npm run dev` on macOS or Linux.
4. Open the local URL shown in the terminal.

The project is built with React, TypeScript, Next.js-compatible routing and vinext/Vite.

## Important notes

- The enquiry form is currently a visual prototype and does not send information.
- Connect the form to the preferred email provider, CRM or backend before launch.
- Confirm final service descriptions, office details and legal pages before launch.
- The BVS photographs were taken from the business's Google Business listing at the owner's request.
- Replace the preview domain with the final production domain in the deployment configuration.
